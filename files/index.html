Board state



  
Copy board state fills this box and copies it, including the fight so far if one is running. Paste it into the chat to report a movement or targeting problem. Positions are top or bot, a row letter a-d counting out from the centre, then a column 1-7. To rebuild a board, paste a state here and press Load.

  

  







Unit roster (CSV)



  
Import a CSV with one row per unit and its 1-star base stats, then pick the unit in the Unit menu before placing it. Columns you leave out use the role defaults.

  

  
Paste CSV text or see the expected columns
    
Headers are case-insensitive. Accepted: name, role (for example Attack Tank), damage_type, hp, ad, ap, attack_speed, armor, magic_resist, range, crit_chance, crit_damage, damage_amp, durability, mana, mana_per_attack, mana_per_second. Write percentages as 25, not 0.25. Optional extras: cost (1 to 5, groups the builder), image (an https URL or a data:image URI) and traits (semicolon-separated names, for example Lunar;Spellweaver). A traits.csv file imports the same way.
