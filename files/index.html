TFT fight simulator

Place units, click one to edit its stats, then start the fight or run 200 seeded fights.

Dot colour is damage type (orange attack, purple magic, teal hybrid). Blue bar under health is mana. The same seed always replays the same fight.

Team builder

Drag a unit onto the board (the half you drop it on decides its team), or click to add it to the Blue side and right-click for the other side. Clicked units go to the front rows if melee and the back rows if ranged. Drag units already on the board to move or swap them.

Unit roster (CSV)

Import a CSV with one row per unit and its 1-star base stats, then pick the unit in the Unit menu before placing it. Columns you leave out use the role defaults.

Paste CSV text or see the expected columns

Headers are case-insensitive. Accepted: name, role (for example Attack Tank), damage_type, hp, ad, ap, attack_speed, armor, magic_resist, range, crit_chance, crit_damage, damage_amp, durability, mana, mana_per_attack, mana_per_second. Write percentages as 25, not 0.25. Optional extras: cost (1 to 5, groups the builder) and image (an https URL or a data:image URI).
